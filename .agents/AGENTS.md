# Workspace Rules

## Documentation Style & Formatting
- **Không sử dụng Icon / Emoji trong tất cả các file Markdown (.md)**: Khi tạo hoặc cập nhật bất kỳ file Markdown (.md) nào trong dự án, tuyệt đối không lạm dụng hoặc chèn thêm emoji/icon (ví dụ: 🌟, 🗺️, 📘, 🔐, 📌, 🚀, 💡, ⚡, 🛠️...). Luôn giữ trình bày tài liệu chuyên nghiệp, tinh gọn và rõ ràng.
